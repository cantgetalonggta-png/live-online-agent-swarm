## Chapter 1 — Latent Vector Space (LVS)

### Foundational Theory
A latent vector space is a high-dimensional numeric field where meaning is geometry. Claims, documents, agents, and hypotheses occupy positions. Distance is disagreement; direction is a modifier. Superposition is the failure mode when the object grammar is too coarse.

### Phase 1 — Preparation
#### Declare objects
**Why:** Wrong unit of analysis makes every similarity a lie.
**Execution:** (1) Object types: Document, Chunk, Entity, Claim, Hypothesis, Agent, Modifier, Artifact. (2) Stable IDs: C01…, H1…, sk_*, agent ids. (3) Forbid pooling 557 pages into one vector. (4) Provenance: page, timestamp, hash.
**KPI:** Every object type has an example ID.

#### Choose decision axes
**Axes:** (A) SOLID/CONTESTED/OVERSTATED/IRREGULARITY (B) H1/H2/H3 support (C) source quality (D) conflict-of-interest.
**KPI:** New claim plotable on all four axes in <2 minutes.

### Phase 2 — Execution
Hash source → section extract → claim split → Claim—SUPPORTED_BY→Source edges. Preserve rare IDs (R01AI110964, DEFUSE, March 25).
