Chapter 1 — Latent Vector Space

Meaning is geometry. Claim-grain atoms. Axes: epistemic tag · hypothesis · source quality · conflict.

Phase 1 — Preparation

p1s1 Declare objects — Document, Chunk, Entity, Claim, Hypothesis, Agent, Modifier, Artifact. Stable IDs. No 557-page single vector.

KPI: object registry with example IDs; no unlabeled blobs.

p1s2 Decision axes — SOLID/CONTESTED/OVERSTATED/IRREGULARITY; H1/H2/H3; source quality; COI. Confidence ≠ probability.

KPI: new claim plotable on 4 axes in <2 min.

Phase 2 — Execution

p2s1 Ingest claim grain — Hash → extract → density log → claim split → graph edges.

p2s2 Re-project — New primary sources move geometry; version + lineage on tag flips.

Phase 3 — Optimization

p2opt1 Split blended claims — No process+origin in one sentence. Sparsity / separability.

Pitfall: spicy blended claims that "read well" hide OVERSTATED clauses.
