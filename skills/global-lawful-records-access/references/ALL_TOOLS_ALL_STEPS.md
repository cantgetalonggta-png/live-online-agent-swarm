## Universal step sequence (any type)

1. **Classify** type + jurisdiction + barrier.
2. **Authorize** (public / fee / FOIA / library / role).
3. **Select portal** from table above.
4. **Search** with exact name + variants + IDs.
5. **Retrieve** only public or fee-paid authorized docs.
6. **Prove** URL, time, hash, portal name.
7. **Minimize** personal data; tag confidence.
8. **Persist** to vault; log negatives.
9. **Escalate lawfully** (FOIA appeal, counsel, fee) if blocked.
10. **Never** bypass technical or legal barriers.

## Specialty deep steps — Business

1. Find jurisdiction of formation (OpenCorporates helps).
2. Pull formation docs + latest annual.
3. List officers/directors/agents.
4. Map parent/sub via filings.
5. For US public: last 3 years 10-K + recent 8-K.
6. UCC search for liens on business name.
7. CourtListener party search for litigation.

## Specialty deep steps — Deeds / property

1. Normalize address → county / BBL.
2. Assessor: tax owner of record.
3. Recorder/ACRIS: document IDs for deeds/mortgages.
4. Download or fee-order deed images.
5. Chain of title: grantor→grantee sequence.
6. Note sponsor/condo units with no individual deed (corporate hold).
7. Cross-link entity owners back to SOS/EDGAR.

## Specialty deep steps — Legal filings

1. Identify court system (federal SDNY, state, etc.).
2. Party name search on CourtListener.
3. Open docket; list document numbers.
4. Download public PDFs; skip sealed.
5. Extract captions, parties, counsel, dates.
6. Cite case number + doc number + court.
7. If need sealed: stop for counsel strategy.
