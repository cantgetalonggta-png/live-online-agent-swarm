# Operational Checklist — Canada / BC + Library Path

**Lawful only.**

## Intake
- [ ] Purpose stated
- [ ] Type: business · property · court · academic · news · government · statute · standard
- [ ] Jurisdiction: federal / BC / other province / municipal
- [ ] Barrier: paywall · login · fee · geo · sealed · subscription
- [ ] Auth doctrine OK
- [ ] HITL if bulk

## Business
- [ ] BC Corporate Online and/or Corporations Canada
- [ ] Provincial registry if not BC/federal
- [ ] OpenCorporates cross-check
- [ ] Directors, office, annuals captured
- [ ] Fee paid if required

## Property
- [ ] Address / PID / owner known
- [ ] BC LTSA (or provincial land) title search
- [ ] Charges / liens / plans retrieved
- [ ] Municipal tax portal context
- [ ] Statutory fee paid

## Court
- [ ] Court Services Online / provincial / federal portal
- [ ] CanLII for decisions
- [ ] Public vs sealed / publication ban checked
- [ ] Fee for public copies if needed
- [ ] Sealed → counsel only

## Library / premium
- [ ] Valid library card (Surrey / VPL / other / university)
- [ ] Logged in with own credentials
- [ ] JSTOR / ProQuest / LexisNexis / Gale / EBSCO as needed
- [ ] ILL filed if missing
- [ ] No login sharing / no ToS-breaking scrape

## Academic / author
- [ ] Unpaywall / arXiv / SSRN / PMC / CORE / BASE / DOAJ
- [ ] Author / institutional repository copy
- [ ] No pirate host

## Government open data / FOI
- [ ] open.canada.ca / BC Data Catalogue / municipal / StatCan
- [ ] FOI/ATI filed if unpublished (track ID)

## Ownership / role
- [ ] Own purchase/subscription export if applicable
- [ ] Role auth documented before restricted portal

## Close
- [ ] URL + time + portal logged
- [ ] Hash if evidence
- [ ] SOLID/MAYBE tags
- [ ] Minimize PII (PIPEDA-aware)
- [ ] Dual-persist
