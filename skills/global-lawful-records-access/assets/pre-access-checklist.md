# Pre-Access Checklist (print / log every job)

- [ ] Information type identified
- [ ] Country / state / county identified
- [ ] Barrier type identified
- [ ] Authorization doctrine satisfied
- [ ] Ownership / public status checked
- [ ] Barrier validity respected (no circumvention plan)
- [ ] Preferred portal selected from country-portals.md
- [ ] Fee / FOIA / library path noted if needed
- [ ] Provenance plan (URL, timestamp, hash if evidence)
- [ ] legal-osint-compliance-layer gates passed
- [ ] HITL obtained if bulk or irreversible
- [ ] Data minimization applied
- [ ] If no lawful path → STOP and document
