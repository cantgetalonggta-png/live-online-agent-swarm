# Encyclopedia 01 — Primary Document Hierarchy

## Foundational theory
Epistemic strength is a partial order, not a vibe. A primary document is one that *is* the act (order, debarment notice, statute, grant term, transcript under oath) or the contemporaneous record of the act (FOIA email chain, production log). Secondary is interpretation.

## Hierarchy (highest → lowest for SOLID eligibility)
1. **Operative government acts**: HHS debarment notice, NY March 25 Directive, statutes, court judgments
2. **Oath / transcribed interview** under subcommittee authority
3. **FOIA email chains / original grant progress reports**
4. **OIG / GAO audit products** with method stated
5. **IC declassified assessments** (with confidence language intact)
6. **Peer-reviewed primary data papers** (sequences, epidemiology)
7. **Major secondary journalism** summarizing 1–6 (never alone for SOLID)
8. **Social media / anonymous leaks** (watchlist only)

## Nested execution
1. For claim C:
   a. List asserted proposition
   b. Ask: is there an operative act? If yes, cite PDF page + URL
   c. If only media, tag FOUND_REF max unless FOIA attached
2. Dual citation lock for SOLID process claims
3. Origin claims require biological primary (sequence/notebook/host) — none public for smoking gun

## Pitfalls
- Treating CIA low-confidence lean as SOLID origin (fails M8)
- Treating HHS debarment as proof EcoHealth created SARS-CoV-2 (fails M5)
- Using single OIG estimate as exact PPP $ without method (fails Range-Not-Meme)

## KPI
Every SOLID claim has ≥1 tier-1–4 source with URL or SSCP page.
