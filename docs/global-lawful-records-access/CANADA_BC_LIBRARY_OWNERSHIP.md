## PHASE A — Canada / BC public registries

### Business records (Canada)
| Tool | Scope | Steps |
|---|---|---|
| **BC Corporate Online** | BC corporations / societies | Search name/number → pay fee if required → incorporation, annual reports, registered office, directors |
| **Canada Business Registry / Corporations Canada** | Federal corporations | Search → directors, status, registered office |
| **Provincial registries** (ON, AB, QC, etc.) | Province of formation | Same pattern as SOS |
| **OpenCorporates** | Cross-border mirror | Discover jurisdiction → then official register |
| **SEC EDGAR** | US cross-border entities | When Canadian story touches US issuer |

**Step-by-step (business):**
1. Identify formation jurisdiction (federal vs provincial).
2. Open official registry (BC Corporate Online if BC).
3. Search business name, number, or director.
4. Retrieve incorporation docs, annual reports, registered office, directors.
5. Pay statutory fees when required (lawful).
6. Cross-check OpenCorporates for multi-jurisdiction aliases.

### Property & land title (Canada / BC)
| Tool | Scope |
|---|---|
| **BC Land Title & Survey Authority (LTSA)** | BC titles, charges, liens, plans |
| **Provincial land registries** | Other provinces |
| **Municipal property tax portals** | Assessment / owner mailing (public fields vary) |

**Step-by-step (property):**
1. Search by address, PID (parcel identifier), or owner.
2. Request title search / documents via LTSA or provincial system.
3. Pay statutory fee.
4. Download deed/title, charges, liens, easements, plans.
5. Municipal tax portal for assessment roll context (not a substitute for title).

### Court records (Canada)
| Tool | Scope |
|---|---|
| **Court Services Online (BC)** | BC court filings / schedules (public subset) |
| **Federal Court / SCC portals** | Federal matters |
| **Provincial court portals** | Other provinces |
| **CanLII** | Decisions / statutes (not full dockets) |
| **PACER / CourtListener** | When US filings involved |

**Step-by-step (court):**
1. Search case number or party name.
2. Separate **public** vs **sealed / restricted** (family, youth, publication bans).
3. Pay retrieval fee for public copies when required.
4. Download only public filings.
5. Sealed / banned → counsel or court order path only.

## PHASE B — Library systems (premium databases, lawful)

Libraries **already pay** for subscriptions. Using a card you hold is authorized access.

| System | Notes |
|---|---|
| **Surrey Public Library** | Digital resources with card |
| **Vancouver Public Library** | Strong database suite |
| **Other public libraries (Canada / USA)** | Gale, EBSCO, PressReader, etc. |
| **University libraries (walk-in / alumni)** | JSTOR, ProQuest, LexisNexis (rules vary) |
| **Interlibrary loan (ILL)** | Request specific articles/books |

**Step-by-step:**
1. Obtain a valid library card (residency rules apply).
2. Log into library digital portal with **your** credentials.
3. Access premium DBs: JSTOR, ProQuest, LexisNexis, Gale, EBSCO, newspaper archives.
4. Download under library license terms (personal/research use; no bulk resale).
5. Use ILL when local holdings miss the item.
6. **Never** share library logins or automate mass scrape of licensed DBs against ToS.

## PHASE G — Ownership doctrine (your accounts)
If **you** purchased or subscribed:
1. Log in with **your** account.
2. Use “Download my data” / export / library / order history.
3. Export only content you are entitled to under the ToS you accepted.  
No shared credentials, no account takeover.

## PHASE I — Paywall alternatives (legal only)
1. Identify paywalled item.
2. Search: library DB · OA · press release · government summary · author copy · public-domain reprint · statutory registry extract of same facts.
3. Retrieve equivalent **lawfully**.  
Never crack the paywall.

## Geographic restrictions
- Use **jurisdiction-correct** portal (BC LTSA for BC land; not a US county recorder).
- VPN to evade geo-blocks on licensed content **is not** advised in this skill when it violates license terms — use library/OA/FOI instead.
- Official government portals for that country remain the primary path.

---

## Combined Canada investigation recipe
```
Name/entity
  → BC Corporate Online / Corporations Canada / OpenCorporates
  → officers + registered office addresses
  → BC LTSA / municipal tax (PID/address)
  → Court Services Online / CanLII / Federal Court
  → Library card → LexisNexis/ProQuest if news or secondary
  → Open data / FOI if still missing
  → Provenance + hash + dual-persist
```

## Hard stops (Canada-aware)
- Publication bans / sealed youth/family files → no access without lawful exception
- LTSA credentials are personal — no sharing
- Library licenses ≠ unlimited commercial redistribution
- No FOI/ATI hacking; use statutory request channels
