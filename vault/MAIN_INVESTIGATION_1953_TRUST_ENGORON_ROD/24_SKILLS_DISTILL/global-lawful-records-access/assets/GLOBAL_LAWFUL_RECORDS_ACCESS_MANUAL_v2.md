# Global Lawful Records Access Manual (v2)

**Lawful channels only. No illegal circumvention. No exploits. No security bypass.**  
Maximum-detail operational blueprint for accessing information legally when it is normally behind paywalls, logins, or restricted portals — via **authorized alternative channels only**.

---

# Part 0 — Master doctrines

1. **Authorization** — public portal, statutory fee, FOIA/FOI/ATI, library card you hold, employment, court order, client permission, or content you purchased.
2. **Ownership** — export your own account data; do not use others’ credentials.
3. **Barrier validity** — paywalls, logins, geo-blocks, CAPTCHAs, sealed files, and robots.txt are real. Alternatives must be lawful (OA, library, registry fee, FOI, counsel), never cracked.

**Categories:** business · property · court · academic · news · government · corporate · legal statutes · technical standards  

**Barriers:** paywall · login · subscription · role-based · geographic · fee · sealed

# Part 3 — Flowchart decision tree

```
START → TYPE → JURISDICTION (US / CA-BC / UK / …) → BARRIER → AUTHORIZED?
  NO → STOP (FOI, fee, library card, counsel, court order, purchase)
  YES ↓
  BUSINESS → SOS / EDGAR / BC Corporate Online / Corporations Canada / Companies House / …
  PROPERTY → County recorder / ACRIS / BC LTSA / HM Land Registry / …
  COURT    → CourtListener→PACER / CSO BC / CanLII / national portals; sealed=counsel
  ACADEMIC → Unpaywall → OA → library → author copy; never pirate
  GOV      → Open data → FOIA/FOI/ATI
  NEWS     → press / wire / library DB / Wayback
  LOGIN    → your credential or documented role only
AFTER → URL+time+portal → hash → tag → minimize → persist → END
```

# Part 5 — Specialized: business, deeds, legal filings

## Business
Get: articles, annuals, directors, agents, charges, 10-K, 990.  
CA: BC Corporate Online / Corporations Canada. US: SOS+EDGAR. UK: Companies House.  
Schema: entity, jurisdiction, reg#, status, officers, agent, address, filing_date, url, time, hash.

## Deeds / land
Get: title, charges, liens, plans, tax owner.  
CA: BC LTSA by address/PID. US: county + ACRIS. UK: HM Land (fee).  
Occupancy without unit deed → corporate/sponsor hold pattern (structure note).  
Schema: address, PID/parcel/BBL, owner, doc_id, type, date, grantor, grantee, url, time, hash.

## Legal filings
Get: public pleadings, orders, judgments, dockets, CanLII decisions.  
Not: sealed, publication bans, youth/family restricted without lawful access.  
US: CourtListener → PACER. BC: Court Services Online.  
Schema: case, number, court, doc#, type, filed, parties, counsel, url, time, hash.

## Combined recipe
Entity → registry officers/addresses → land title → court portals → library secondary → open data/FOI → graph → dual-persist.

# Part 6 — Paywall / login / geo — legal alternatives only

| Barrier | Legal route |
|---|---|
| News paywall | Library DB, press release, wire free tier, government summary |
| Journal paywall | Unpaywall, preprint, author copy, library JSTOR/ProQuest, ILL |
| Corporate DB paywall | Official registry statutory extract (often cheaper/primary) |
| Login portal | Your account, library card, role authorization, FOI release |
| Geo block on license | Local library / national OA / FOI — not license-violating VPN abuse |
| Sealed court | Counsel + motion / statutory exception |

# Part 7 — Never-do list

- Crack paywalls or logins  
- CAPTCHA farms / bot evasion of security  
- Credential stuffing or shared PACER/library fraud  
- Access sealed / publication-banned files without authority  
- Pirate academic (Sci-Hub etc. as method)  
- Hack FOIA/FOI systems  
- Bulk private personal data beyond public-record ceiling
