# USA Deep Dive — Business, Property, Court, Government

## Business
1. **Public companies:** EDGAR full-text search → company CIK → filings browser → download HTML/XML.
2. **Private companies:** State SOS (Delaware Division of Corporations, California SOS, NY DOS, Florida Sunbiz, Texas SOS, etc.).
3. **UBOs / officers:** Often on annual report PDFs; OpenCorporates aggregates.
4. **Liens / UCC:** State UCC search portals.

## Property (county-first model)
1. Convert address → county.
2. Recorder grantor/grantee or parcel search.
3. ACRIS (NYC Manhattan block/lot) Open Data for bulk parties/legals.
4. Assessor for tax owner mailing address (public).
5. Copy fees for certified deeds are **lawful** statutory access.

## Courts
1. Federal: PACER → case number / party → docket → PDFs (cost).
2. Free path: CourtListener RECAP first.
3. State: e.g. NYSCEF, California courts, Florida courts — vary by state.
4. Sealed docs: require motion / order — do not attempt other access.

## Government / FOIA
1. Agency FOIA reading room.
2. foia.gov multi-agency request.
3. Appeal denials per agency regulations.
4. Mandatory declassification / other special regimes as applicable.

## Practical investigation stack (matches 301 E 66 workflow)
ACRIS Open Data → parties/legals join → JustFix portfolio officers → county fee deeds for specific lots → PACER/CourtListener for civil captions → EDGAR/SOS for entity officers.
