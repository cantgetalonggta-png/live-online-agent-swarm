# Country / Jurisdiction Portal Master List (Lawful)

## United States
| Need | Portal | Notes |
|---|---|---|
| Federal corp | https://www.sec.gov/edgar | Free |
| State corp | Search “[State] Secretary of State business search” | Free/low fee |
| Nonprofits | https://apps.irs.gov/app/eos/ | 990s |
| Global corp mirror | https://opencorporates.com | Free tier |
| Federal courts | https://pacer.uscourts.gov | Paid; fee waiver path |
| Free federal dockets | https://www.courtlistener.com | RECAP |
| FOIA | https://www.foia.gov | Request tracker |
| Open data | https://data.gov | Free |
| NYC property | https://a836-acris.nyc.gov + Open Data `8h5j-fqxa` | Free search; images fee |
| County deeds | County recorder / clerk website | Varies by county |
| Assessors | County assessor / GIS | Free valuations |
